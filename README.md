# PortScan Android

[PortScan](https://portscan.co.kr) 안드로이드 앱 배포용 저장소입니다. 소스 코드는 여기 없습니다.

## 설치
1. [Releases](https://github.com/rsody/portscan-app/releases/latest)에서 `portscan.apk`를 받습니다.
2. 설치할 때 "출처를 알 수 없는 앱" 허용이 필요합니다.

Google Play 출시 전 버전입니다. Android 10 이상.

- 패키지: `kr.co.portscan.app`
- 서명 인증서 SHA-256: https://portscan.co.kr/.well-known/assetlinks.json 에 공개된 값과 같습니다.

## 브라우저 확장 (크롬·엣지)
1. [extension-v1.0.0](https://github.com/rsody/portscan-app/releases/tag/extension-v1.0.0)에서 `portscan-extension.zip`을 받아 압축을 풉니다.
2. 크롬은 `chrome://extensions`, 엣지는 `edge://extensions`를 열고 개발자 모드를 켭니다.
3. "압축해제된 확장 프로그램 로드"로 푼 폴더를 선택합니다.

스토어 등록 전 버전입니다. 권한은 activeTab·contextMenus뿐이며 개인정보를 수집하지 않습니다.
